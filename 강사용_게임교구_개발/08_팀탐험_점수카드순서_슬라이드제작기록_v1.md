# 팀탐험 보상카드 점수카드순서 슬라이드 제작 기록 v1

## 제작 목적

`점수카드.pptx`의 7장 흐름을 유지하되, 판타지 아이템 카드 체계를 `팀탐험 보상카드` 체계로 바꿔 안내 슬라이드를 제작했다.

이 덱은 강의 중 상시 노출하는 점수판이 아니다. 강사가 규칙을 안내할 때 사용하고, 실제 점수 합산은 마지막에 진행한다. 핵심 재미는 팀 봉투에 쌓인 카드를 마지막에 열어 합산하는 데 있다.

## 슬라이드 구성

1. 특별한 점수 시스템 소개
   - 활동 참여, 카드 수집, 마지막 공개 구조를 소개한다.
   - 점수판 없이 팀 봉투에 카드를 모으는 운영 방식을 안내한다.

2. 탐험 카드 점수 시스템
   - 식량 1점 28%
   - 로프 2점 24%
   - 랜턴 3점 18%
   - 지도 4점 12%
   - 나침반 5점 10%
   - 깃발 6점 8%

3. 탐험 완주 보너스
   - 서로 다른 카드 6종을 한 세트로 모으면 완주 보너스 9점을 더한다.
   - 1점 + 2점 + 3점 + 4점 + 5점 + 6점 + 완주 보너스 9점 = 총 30점.

4. 승패 결과에 따른 카드 랜덤 뽑기
   - 승리: 뽑기 4회
   - 패배: 뽑기 2회
   - 승패는 뽑기 횟수를 바꿀 뿐, 최종 점수는 카드 결과와 세트 완성에 따라 달라진다.

5. 승리팀 랜덤뽑기 예시
   - 식량 1점, 로프 2점, 랜턴 3점, 지도 4점.
   - 총 10점.

6. 패배팀 랜덤뽑기 예시
   - 나침반 5점, 깃발 6점.
   - 총 11점.

7. 조별 랜덤뽑기 최종 예시
   - 1조: 뽑은 카드 14장, 기본 54점, 완주 보너스 2회 × 9점, 총 72점.
   - 2조: 뽑은 카드 18장, 기본 51점, 완주 보너스 2회 × 9점, 총 69점.
   - 3조: 뽑은 카드 12장, 기본 32점, 총 32점.
   - 4조: 뽑은 카드 21장, 기본 40점, 총 40점.

## 디자인 메모

- 원본의 어두운 안내 슬라이드 분위기를 살리되, 탐험 카드 이미지가 잘 보이도록 남색과 크림색을 중심으로 정리했다.
- 표지는 큰 문구의 한글 줄 처리 문제를 피하기 위해 헤드라인을 이미지로 제작했다.
- 수식은 원본 흐름을 유지하되 한 줄로 읽히도록 크기와 간격을 다시 잡았다.
- 7번 슬라이드는 팀별 최종 합산 장면이 바로 읽히도록 표 형태로 정리했다.

## 운영 메모

- 강의 중에는 카드 지급 사유와 뽑기 횟수만 안내한다.
- 팀은 카드를 봉투에 모은다.
- 점수 계산은 마지막에 함께 진행한다.
- 최종 공개 후에는 점수보다 참여 행동, 질문, 팀 협업을 연결해 마무리한다.
