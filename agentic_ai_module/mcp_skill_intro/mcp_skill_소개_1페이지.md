# MCP와 스킬 소개 1페이지

## 핵심 메시지

MCP와 스킬은 오늘 실습이 아니라 다음 확장 단계다.

## 강의 처리

- 일반 직장인 과정에서는 5분 소개만 한다.
- 실제 연결, 권한 설계, 스킬 제작은 심화 과정으로 분리한다.
- 오늘은 Antigravity 설치, Fast 사용, 첫 요청문 작성까지 진행한다.

## 설명 문장

MCP는 AI가 외부 도구와 연결되는 통로다.  
스킬은 반복 업무 방식을 저장해 다시 쓰는 단위다.  
둘 다 업무 효율을 높일 수 있지만 권한과 보안이 함께 커지므로, 오늘은 개념만 다루고 실습은 다음 과정으로 넘긴다.

## 사용 위치

Antigravity 설치 실습 뒤, Codex 비교 시연 전후에 넣는다.
