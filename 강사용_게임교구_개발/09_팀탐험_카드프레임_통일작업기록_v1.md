# 팀탐험 카드 프레임 통일 작업 기록 v1

## 작업 목적

AI로 생성한 단품 카드 이미지의 외곽 크기가 조금씩 달라 인쇄 시 카드 프레임이 제각각으로 보일 수 있었다. 이를 막기 위해 인쇄용 단품 카드 이미지를 같은 픽셀 크기로 맞췄다.

## 처리 내용

- 원본 단품 카드 이미지는 그대로 보존했다.
- 인쇄용 통일본을 새 폴더에 생성했다.
- 모든 단품 카드와 공통 뒷면을 `1050×1500px`로 맞췄다.
- 슬라이드 제작용 카드 자산도 같은 크기로 갱신했다.
- 갱신한 카드 자산으로 점수카드순서 덱과 운영 안내 덱을 다시 생성했다.
