# 충주문화관광재단 팀 대상 AI 교육 사례·실습안

## 과정 적용 방향

- 대상: 충주문화관광재단, 문화도시센터, 문화사업·관광·홍보·예술지원·운영 담당자
- 성격: B2B 공공문화 실무형 AI 활용 교육
- 핵심 관점: AI 기능 소개보다 문화기획자의 질문, 판단, 자료 해석, 시민 접점 설계를 앞에 둔다.
- 강의 목표: 재단 업무에서 반복되는 기획, 모집, 홍보, 운영, 정산, 성과 정리를 AI와 함께 처리하는 방법을 익힌다.

## 기존 4시간 과정에 넣을 실습 교체안

### 1. 현재 활용 위치 체크

기존 질문을 재단형으로 바꾼다.

```text
나는 AI를 재단 업무에서 주로 어디에 쓰고 있습니까?

1. 홍보문 초안
2. 보도자료·공고문 정리
3. 회의록·결과보고서 요약
4. 프로그램 기획 아이디어
5. 자료 검토와 운영 판단 보조
6. 아직 거의 쓰지 않음
```

산출물:

```text
내가 AI와 함께 개선하고 싶은 재단 업무 장면은 ________이다.
```

### 2. 목적 발견 질문 사다리

공통 주제:

```text
관아골 문화마당 참여 공간을 모집해야 한다.
```

질문:

```text
1. 단순히 모집 인원을 채우는 것이 목표인가, 좋은 파트너 공간을 찾는 것이 목표인가?
2. 참여 공간이 실제로 얻어야 할 이익은 무엇인가?
3. 시민은 이 프로그램을 어떤 말로 이해해야 참여할까?
4. 담당자는 어떤 자료가 있어야 빠르게 실행할 수 있을까?
5. 이 일이 끝났을 때 재단에 필요한 성과 자료는 무엇인가?
```

산출물:

```text
이 사업에서 AI에게 맡길 일은 ________이고, 사람이 직접 결정할 일은 ________이다.
```

### 3. CRAFTO 실습

실습 주제:

```text
충주형 생활권 국악 프로그램 참여 공간 모집 안내문을 작성한다.
```

작성 예시:

```text
Context:
충주 문화도시 사업의 일환으로 카페, 공방, 서점 같은 생활권 공간에서 국악 향유 프로그램을 운영하려 한다.

Role:
지역 문화사업 실무를 이해하는 문화기획 파트너

Audience:
충주와 충청권의 로컬 공간 운영자, 예술단체, 시민기획자

Format:
모집 안내문 1장, 참여 이점 5개, 문의 응대 FAQ 8개

Tone:
공공기관 문서답게 명확하되, 지역 파트너가 부담 없이 이해할 수 있는 문체

Option:
예산과 세부 일정은 샘플 자료 밖에서 추정하지 말 것. 불확실한 항목은 질문으로 돌릴 것.
```

### 4. 소스 기반 AI 실습

샘플 자료:

- 사업 개요 1장
- 장소 후보 목록 1장
- 시민 페르소나 1장
- 운영 메모 1장
- 홍보 채널 메모 1장

요청문:

```text
이 자료만 사용해서 관아골 문화마당 운영 준비안을 정리해 주세요.

1. 시민 대상 안내문
2. 참여 공간 운영 체크리스트
3. 예상 리스크와 대응표
4. 홍보 채널별 문안

자료 밖 내용은 추정하지 말고, 필요한 질문을 별도로 적어 주세요.
```

### 5. 10-80-10 + 1-3-1 실습

주제:

```text
충주파크뮤직페스티벌 with gugak 홍보 방향을 정한다.
```

처음 10:

```text
사람이 정할 것:
- 이번 홍보의 핵심 대상
- 과장하면 안 되는 표현
- 반드시 살릴 충주성
```

중간 80:

```text
AI에게 맡길 것:
- 홍보 방향 3안
- 각 안의 장점과 리스크
- SNS, 보도자료, 현장 안내문 문안
```

마지막 10:

```text
사람이 결정할 것:
- 최종 홍보 방향 1개
- 쓰지 않을 표현
- 현장 운영상 추가 보완할 항목
```

### 6. 피드백 루프 실습

점검 역할:

```text
1. 시민 관점: 이해하기 쉬운가
2. 예술인 관점: 창작자와 참여자의 존중이 지켜지는가
3. 행정 관점: 운영상 빠진 항목은 없는가
4. 관광객 관점: 방문 이유가 충분한가
```

요청문:

```text
아래 홍보문을 네 가지 관점으로 검토해 주세요.
각 관점에서 수정할 문장, 보완할 정보, 운영상 주의할 항목을 나눠 주세요.
최종 문장은 담백한 공공기관 문체로 다시 작성해 주세요.
```

## Agentic AI 실습 과제

### 실습명

문화도시 충주 행사 운영 폴더를 에이전트에게 맡기기

### 실습 목표

AI에게 단순 답변이 아니라 폴더 안의 자료를 읽고, 작업계획을 세우고, 산출물을 만드는 과정을 경험한다.

### 폴더 구성

```text
sample_workspace_chungju/
  input/
    01_사업개요_관아골문화마당.md
    02_장소후보_생활권공간.md
    03_참가자페르소나.md
    04_운영메모.md
    05_홍보채널메모.md
  output/
```

### 첫 요청문

```text
현재 열린 폴더의 input 자료만 읽고 문화도시 충주 관아골 문화마당 운영 준비물을 만들어 주세요.

목적:
담당자가 바로 검토할 수 있는 실무 자료를 만드는 것입니다.

작업 범위:
input 폴더 안의 자료만 사용하세요.
실제 내부 정보, 개인정보, 예산 세부 금액은 추정하지 마세요.

진행 방식:
먼저 작업계획을 제시하세요.
제가 승인하면 output 폴더에 아래 파일을 만들어 주세요.

필요 산출물:
1. 참가자 안내문.md
2. 참여 공간 운영 체크리스트.md
3. 리스크 대응표.md
4. SNS 홍보문안.md
5. 담당자 추가 질문.md

사람에게 물어볼 조건:
자료가 부족하거나 실제 승인권자 판단이 필요한 경우에는 작업을 멈추고 질문하세요.
```

### 성공 조건

- 작업계획을 먼저 받는다.
- 산출물이 output 폴더에 생성된다.
- 자료 밖 추정과 실제 개인정보 사용이 없다.
- 사람이 최종 문구와 운영 결정을 맡는다.
