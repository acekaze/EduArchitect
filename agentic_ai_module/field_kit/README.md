# Agentic AI 현장 설치 키트

이 폴더는 60~90분 설치·세팅 실습을 위한 보조 자료다.

## 구성

- `agentic_ai_설치_안내.pdf`: 참가자 안내용 1장 PDF
- `antigravity_fast_step_by_step.html`: Fast 기반 설치·세팅 별도 안내 페이지
- `antigravity_fast_step_by_step.pdf`: 출력용 step-by-step 설치 안내 PDF
- `antigravity_현장설치_가이드.md`: 강사용 진행 메모
- `sample_workspace`: 참가자가 Antigravity에서 열 실습 폴더
- `screenshots`: 와이파이 지연이나 설치 실패 때 보여줄 캡처 대체 이미지
- `example_outputs`: 강사용 예시 결과물 보관 폴더. 참가자 배포 ZIP에서는 제외한다.

## 운영 방식

1. 참가자는 `sample_workspace` 폴더를 Antigravity에서 연다.
2. 실제 회사 자료, 개인정보, 계정키는 넣지 않는다.
3. 첫 요청문은 파일을 만들기 전에 계획과 승인 항목을 먼저 묻게 한다.
4. 설치가 안 되는 참가자는 옆 사람과 페어 실습으로 전환한다.
5. 실습 완료는 도구 설치가 아니라 각자의 적용 문장 작성으로 판정한다.
6. 모델 선택 화면이 나오면 무료 Fast 또는 빠른 기본 모드를 우선 사용한다.
