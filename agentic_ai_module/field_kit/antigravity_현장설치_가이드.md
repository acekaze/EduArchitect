# Antigravity 현장 설치 가이드

## 수업 전 준비

- 강사용 노트북에서 Antigravity 설치와 로그인 흐름을 리허설한다.
- `sample_workspace` 폴더를 압축 파일로 준비한다.
- 다운로드 지연에 대비해 설치 URL과 안내 PDF를 첫 화면에 띄운다.
- 관리자 권한이 없는 참가자를 위해 2인 1조 전환 멘트를 준비한다.

## 현장 진행

### 1. 다운로드와 로그인

- Antigravity 다운로드 페이지를 연다.
- 운영체제에 맞는 설치 파일을 내려받는다.
- 로그인 후 빈 창이 열리면 실습 폴더를 연다.
- 모델 선택 화면이 나오면 무료 Fast 또는 빠른 기본 모드를 우선 고른다.
- 고성능 모델, 외부 API, self-hosted 도구 연결은 실습 뒤 확장 옵션으로 소개한다.

### 2. 실습 폴더 열기

- `sample_workspace` 폴더를 선택한다.
- `input` 폴더의 자료만 읽게 한다.
- `output` 폴더에 결과물을 만들게 한다.

### 3. 첫 요청문

```text
이 폴더는 Agentic AI 설치 실습용 샘플 폴더야.

먼저 폴더 안의 자료를 읽고,
1. 네가 이해한 업무 목적
2. 만들 수 있는 산출물
3. 파일을 만들기 전 필요한 질문
4. 승인받아야 할 행동
을 정리해줘.

내가 승인하기 전에는 파일을 만들거나 수정하지 마.
```

### 4. 공통 실습 과제

```text
input 폴더의 자료를 바탕으로
1. 참가자 안내문
2. 운영 체크리스트
3. 리스크 대응표
초안을 만들어줘.

결과물은 output 폴더에 각각 별도 파일로 저장해줘.
저장 전에는 파일명과 구성안을 먼저 제시해줘.
```

## 오류 대응

| 상황 | 조치 | 운영 |
| --- | --- | --- |
| 관리자 권한 없음 | 옆 사람과 페어 실습 | 요청문 작성과 결과 점검 역할 부여 |
| 로그인 지연 | 브라우저 재시도 | 강사 화면을 따라 요청문 작성 |
| 와이파이 지연 | 샘플 폴더를 로컬 공유 | 설치 대신 안전 세팅 실습 진행 |
| 설치 실패 | 페어 실습 전환 | 마지막 적용 문장은 개인별 작성 |
