# 07. 팀 탐험 매뉴얼 슬라이드 제작 기록 v1

## 1. 제작 목적

이 문서는 `팀 탐험 보상 카드`의 강사용 안내 매뉴얼과 참가자 안내 슬라이드 제작 기록이다. 카드 이미지가 만들어진 뒤, 현장에서 바로 설명하고 운영할 수 있는 자료로 패키지화하는 것이 목적이다.

## 3. 매뉴얼 구성

매뉴얼은 강사가 읽고 바로 운영할 수 있도록 다음 흐름으로 구성했다.

1. 도구 개요
2. 사용 장면
3. 준비물
4. 카드 구성
5. 참가자 안내 멘트
6. 카드 지급 방식
7. 전체 운영 흐름
8. 정산 예시
9. 강사용 운영 노하우
10. 흔한 상황 대응
11. 변형 운영
12. 마무리 메시지

## 4. 슬라이드 구성

슬라이드는 참가자에게 보여줄 안내 화면 중심으로 제작했다.

1. 표지
2. 운영 철학
3. 오늘의 규칙
4. 탐험 카드 6종
5. 완주 보너스
6. 카드 지급 행동
7. 진행 중 안내
8. 마지막 정산 순서
9. 마무리 멘트

## 5. 제작 원칙

- 매뉴얼은 강사용 세부 운영 문서로 만든다.
- 슬라이드는 참가자 안내용이므로 설명을 길게 넣지 않는다.
- 점수판 없이 마지막 정산의 기대감을 살린다.
- 보상은 정답보다 학습 행동에 붙인다.
- 카드 이미지는 SVG형 시안이 아니라 AI 생성 단품 카드 이미지를 사용한다.

## 6. QA 기록

매뉴얼

- DOCX 생성 후 페이지 PNG 렌더를 진행했다.
- 총 5페이지로 렌더했다.
- 표, 안내 멘트, 마무리 문구가 읽히는지 점검했다.

슬라이드

- PPTX 생성 후 9장 PNG 렌더를 진행했다.
- 생성 원본 렌더와 저장된 PPTX 재불러오기 렌더를 모두 만들었다.
- 텍스트 겹침, 이미지 누락, 여백 문제를 점검했다.
