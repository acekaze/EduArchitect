# 감정단어카드 간소화 작업 기록 v2

## 작업 방향

`감정 신호 카드 v1`은 감정 이름, 설명, 필요한 것, 다음 행동까지 한 장에 담았다. 정보가 많아 강의 현장에서 빠르게 고르기에는 무거웠다.

`v2`는 앞면을 감정 단어와 짧은 설명만으로 줄였다.

## 앞면 구성

- 감정 단어
- 감정에 대한 짧은 설명
- 분류별 색상 테두리

분류명, 카드 ID, 필요한 것, 다음 행동은 앞면에서 제외했다.

## 줄바꿈 처리

감정 단어는 한 줄을 유지한다. 긴 단어는 크기를 줄여 카드 안에 맞춘다.

설명 문장은 단어 단위로 줄을 나누며, 인쇄 시 어색한 끊김이 생기지 않도록 문장을 짧게 다듬었다.

## 폰트 처리

감정 단어는 굵고 둥근 인상의 헤드라인체를 사용한다.

설명 문장은 가독성을 위해 산세리프 계열을 사용한다. 단어와 설명의 역할 차이를 분명하게 나누기 위한 처리다.

## 운영 방식

참여자는 먼저 단어를 고른다. 설명은 단어가 애매할 때만 읽는다.

강사는 활동 후에 필요한 경우 다음 질문을 붙인다.

- 이 단어를 고른 이유를 한 문장으로 말해 주세요.
- 지금 이 상태에서 팀 활동을 더 잘하려면 무엇이 필요합니까?
- 다음 활동에서 내가 조절할 행동은 무엇입니까?

이 질문은 카드에 넣지 않고 강사용 매뉴얼에 둔다.
