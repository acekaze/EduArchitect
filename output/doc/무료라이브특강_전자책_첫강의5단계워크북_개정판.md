## 이 전자책의 목표

이 전자책은 강사가 되고 싶은 사람이 자기 경험, 전문성, 관심사를 첫 강의 형태로 정리하도록 돕는 작업 문서입니다.

읽기만 하면 좋은 자료로 끝납니다.  
빈칸을 채우면 첫 강의의 방향, 대상, 메시지, 오프닝, 30분 강의안까지 손에 잡힙니다.

이 전자책을 마친 뒤 확보할 결과물은 다섯 가지입니다.

| 결과물 | 내용 |
|---|---|
| 강의 씨앗 1개 | 내가 강의로 바꿀 수 있는 경험, 전문성, 관심사 |
| 대상 정의 | 이 강의를 가장 필요로 하는 사람 |
| 강의 정의 문장 | 누구에게, 무엇을 통해, 어떤 변화를 줄 것인지 담은 한 문장 |
| 오프닝 질문 | 학습자가 강의에 연결되는 첫 질문 |
| 30분 강의안 | 바로 테스트할 수 있는 첫 강의 구조 |

## 사용 방법

이 전자책은 45분에서 70분 정도 시간을 두고 작성하는 것을 권합니다.

완벽하게 쓰려고 하지 마세요.  
처음에는 거칠게 써야 합니다. 강의는 머릿속에서 완성되는 것이 아니라, 써보고 말해보고 고치는 과정에서 실제 형태가 생깁니다.

### 추천 진행 순서

| 시간 | 작업 |
|---|---|
| 5분 | 시작 전 진단 |
| 10분 | 강의 씨앗 찾기 |
| 10분 | 대상과 필요성 정리 |
| 10분 | 강의 정의 문장 작성 |
| 10분 | 오프닝과 질문 설계 |
| 10분 | 30분 강의안 작성 |

### 작성 원칙

1. 누구에게나 좋은 강의를 만들려고 하지 않습니다.
2. 내가 아는 모든 내용을 넣으려고 하지 않습니다.
3. 지식보다 변화를 먼저 생각합니다.
4. 말하기 실력보다 설계의 정확도를 먼저 잡습니다.
5. 마지막에는 반드시 30분 안으로 줄입니다.

## 왜 강의인가

강의는 지식을 나누는 활동처럼 보이지만, 실제로는 신뢰를 만드는 일입니다.

누군가의 시간을 받아 내 앞에 앉게 만들고, 그 사람이 자기 문제를 새롭게 이해하게 만들고, 강의 후 작은 행동이라도 바꾸게 만드는 일입니다.

그래서 강의는 좋은 마케팅이 될 수 있습니다.  
광고는 나를 알립니다. 콘텐츠는 나를 접하게 합니다. 하지만 강의는 상대가 내 사고방식과 문제 해결 과정을 직접 경험하게 합니다.

전문역량이 있는 사람에게 강의는 특히 강력합니다.

| 가진 것 | 강의로 바뀌면 생기는 가치 |
|---|---|
| 직무 경험 | 현장의 문제를 해결하는 교육 |
| 실패 경험 | 같은 문제를 겪는 사람에게 필요한 전환 |
| 전문 지식 | 신뢰와 수익을 동시에 만드는 콘텐츠 |
| 깊은 관심사 | 새로운 관점을 제공하는 시그니처 주제 |
| 사람을 도운 경험 | 영향력 있는 교육 사례 |

강의의 가치는 영향력입니다.  
내가 가진 능력과 경험이 누군가에게 도움을 줄 수 있다는 점, 그리고 그 도움을 통해 신뢰를 얻을 수 있다는 점이 강의의 큰 힘입니다.

하지만 강의는 많은 말을 한다고 만들어지지 않습니다.  
핵심은 한 문장입니다.

> 나는 [누구에게] [무엇을 통해] [어떤 변화]를 돕는 강의를 한다.

이 문장을 만들 수 있으면 첫 강의의 절반은 이미 시작된 것입니다.

| 3-5개 | 강의 씨앗이 있습니다. 대상을 좁히면 첫 강의 주제가 나올 가능성이 큽니다. |

### 여기서 중요한 점

강사는 모든 것을 아는 사람이 아닙니다.  
특정 문제를 먼저 겪고, 더 깊이 고민하고, 더 구조적으로 정리한 사람입니다.

그러므로 첫 질문은 “내가 강사 자격이 있나?”가 아닙니다.

첫 질문은 이쪽에 가깝습니다.

> 내가 먼저 겪었고, 정리했고, 누군가에게 도움이 될 수 있는 것은 무엇인가?

## 강사가 되기 전 버려야 할 오해 5가지

### 오해 1. 유명해야 강사가 된다

처음부터 유명해서 강의하는 사람은 많지 않습니다.  
오히려 작은 모임, 내부 교육, 무료 특강, 스터디, 커뮤니티에서 시작하는 경우가 많습니다.

첫 강의는 유명세보다 문제 해결력이 중요합니다.  
상대가 “이 사람은 내 문제를 이해한다”고 느끼면 다음 기회가 생깁니다.

### 오해 2. 말을 잘해야 강사가 된다

말을 잘하는 것은 도움이 됩니다.  
하지만 강의에서 더 중요한 것은 학습자가 이해하고 정리하고 적용하게 만드는 구조입니다.

말만 좋은 강의는 듣는 순간에는 좋지만 행동으로 이어지기 어렵습니다.  
반대로 말이 아주 화려하지 않아도 대상, 메시지, 질문, 활동이 맞으면 강의는 힘을 가집니다.

### 오해 3. 많이 알아야 강의가 된다

초보 강사가 가장 자주 하는 실수는 많이 넣는 것입니다.  
많이 넣을수록 학습자는 무엇을 가져가야 할지 놓칩니다.

강의는 지식의 양보다 핵심의 선명도가 중요합니다.

### 오해 4. PPT부터 만들면 강의가 빨리 완성된다

PPT는 강의의 결과물이지 출발점이 아닙니다.  
PPT부터 만들면 디자인과 순서에 끌려가고, 정작 학습자의 문제와 변화가 뒤로 갑니다.

먼저 한 문장을 정해야 합니다.  
그다음 흐름을 만들고, 마지막에 슬라이드를 만듭니다.

### 오해 5. 강의는 당일 잘하면 된다

강의는 당일 말하기 전에 이미 절반 이상 결정됩니다.

대상을 어떻게 이해했는지, 어떤 질문을 준비했는지, 오프닝에서 학습 환경을 어떻게 만들었는지, 강의 후 무엇을 정리했는지가 강의 품질을 만듭니다.

# 1단계. 강의 씨앗 찾기

강의 씨앗은 내가 말하고 싶은 주제가 아닙니다.  
상대에게 실제로 도움이 될 수 있는 경험, 전문성, 문제 해결 방식입니다.

강의 씨앗은 보통 다섯 곳에서 나옵니다.

| 씨앗의 출처 | 질문 |
|---|---|
| 경험 | 내가 직접 겪고 통과한 일은 무엇인가 |
| 전문성 | 남보다 오래 다루거나 깊이 공부한 분야는 무엇인가 |
| 실패 | 아프게 배웠고 지금은 설명할 수 있는 것은 무엇인가 |
| 반복 도움 | 사람들이 나에게 자주 도움을 구하는 문제는 무엇인가 |
| 깊은 관심 | 오래 좋아했고 계속 파고든 주제는 무엇인가 |

---

## 사례 1. 실패를 전환한 사람이 다른 사람을 돕는 강사가 될 수 있다

도박중독협회에서 만난 한 수강생이 있었습니다.  
그분은 동료의 배신과 사업 실패로 큰 좌절을 겪고 있었습니다.

그때 중요한 것은 단순한 위로가 아니었습니다.  
사건을 새롭게 해석하는 질문이 필요했습니다.

“이 일이 당신을 끝내는 사건이라면 지금 해야 할 행동은 무엇일까요?”  
“반대로, 이 일이 이후 삶의 방향을 바꾸는 계기라면 지금 해야 할 행동은 무엇일까요?”  
“지금 잃은 것만 적지 말고, 아직 선택할 수 있는 것을 적어보면 무엇이 있습니까?”

그분은 그 질문을 자기 삶에 적용했습니다.  
실패를 단순한 패배로 두지 않고, 다시 시작할 수 있는 해석으로 바꾸었습니다.

이후 취업에 성공했고, 검정고시에도 합격했습니다.  
그리고 “강사님 덕분에 포기하지 않을 수 있었어요”라고 말해주었습니다.

이런 순간이 강사의 보람입니다.

강의는 한 사람의 삶에 직접 관여합니다.  
어색했던 팀이 팀워크를 갖추게 만들 수도 있고, 한 마디도 떼지 못하던 사람이 자기 이야기를 말하게 만들 수도 있습니다.

중요한 것은 대단한 사건이 아닙니다.  
그 사건에서 어떤 질문과 방법을 만들었는가입니다.

### 내게 적용하기

| 질문 | 작성 |
|---|---|
| 내가 지나온 어려움 중 지금은 설명할 수 있는 것은 무엇인가 |  |
| 그 일을 겪으며 얻은 질문이나 방법은 무엇인가 |  |
| 그 방법이 필요한 사람은 누구인가 |  |
| 그 사람이 같은 상황에서 가장 먼저 바꿔야 할 생각은 무엇인가 |  |

## 사례 2. 좋아한 것도 강의가 될 수 있다

한 참가자는 세종대왕을 정말 좋아했습니다.  
단순한 역사 지식이 아니라, 세종이 자신의 삶에 끼친 영향, 세종의 리더십, 세종의 질문 방식을 오래 생각해온 사람이었습니다.

처음에는 “이게 강의가 될까요?”라고 물었습니다.

가능합니다.  
다만 “세종대왕 이야기”로 끝나면 강의가 약해집니다.

강의가 되려면 이렇게 바뀌어야 합니다.

| 약한 주제 | 강의가 되는 주제 |
|---|---|
| 내가 좋아하는 세종대왕 이야기 | 세종의 질문법으로 리더가 팀원의 생각을 끌어내는 방법 |
| 세종의 업적 소개 | 조직에서 사람을 성장시키는 리더의 질문 구조 |
| 세종 리더십 | 일방 지시가 아닌 질문으로 실행력을 만드는 리더십 |

좋아한 것도 강의가 됩니다.  
단, 좋아한 이유가 상대의 문제와 연결되어야 합니다.

### 내게 적용하기

| 질문 | 작성 |
|---|---|
| 내가 오래 좋아한 인물, 분야, 주제는 무엇인가 |  |
| 그 주제가 내 삶에 준 영향은 무엇인가 |  |
| 그 주제에서 뽑을 수 있는 원리는 무엇인가 |  |
| 그 원리가 필요한 사람은 누구인가 |  |

---

## 사례 3. 첫 강의는 작게 시작해도 된다

처음부터 큰 무대에서 시작할 필요는 없습니다.

첫 강의는 5명 이하의 작은 모임일 수 있습니다.  
내가 이미 알고 있는 것을 주변 사람에게 정리해서 전하는 자리일 수도 있습니다.

전종목의 첫 강의도 거대한 기업 강의가 아니었습니다.  
아나운서, 연극, 뮤지컬 경험을 통해 알게 된 음성 표현과 음성 관리 방법을 작은 모임에서 나누는 형태였습니다.

중요한 것은 규모가 아닙니다.

첫 강의에서 해야 할 일은 세 가지입니다.

1. 사람들이 실제로 관심을 갖는지 확인합니다.
2. 내 설명이 이해되는지 듣습니다.
3. 다음에 더 나아질 지점을 기록합니다.

작게 시작해야 빨리 배웁니다.  
작은 강의는 실패 비용이 낮고 수정 속도가 빠릅니다.

# 2단계. WHO와 WHY 정리하기

강의는 “좋은 내용”에서 시작하지 않습니다.  
누가 왜 들어야 하는지에서 시작합니다.

초보 강사가 자주 하는 말이 있습니다.

“이 강의는 누구에게나 필요합니다.”

그럴 수 있습니다.  
하지만 누구에게나 필요하다는 말은 실제 구매와 참여 상황에서는 힘이 약합니다.

강의가 팔리고, 듣고 싶어지고, 끝까지 집중하게 만들려면 특정한 사람이 떠올라야 합니다.

---

## WHO. 이 강의를 가장 필요로 하는 사람

WHO는 단순한 인구통계가 아닙니다.

나이, 성별, 직업도 도움이 되지만 그것만으로는 부족합니다.  
더 중요한 것은 현재 상태입니다.

| 약한 WHO | 강한 WHO |
|---|---|
| 직장인 | 회의에서 생각은 있는데 짧게 말하지 못해 기회를 놓치는 직장인 |
| 리더 | 팀원이 회의에서 말하지 않아 혼자 결론을 내리게 되는 팀장 |
| 예비 강사 | 아이템은 있지만 강의 구조로 정리하지 못한 예비 강사 |
| 부모 | 아이와 대화할 때 훈계로 끝나 관계가 어색해지는 부모 |
| 프리랜서 | 전문성은 있지만 자기 상품을 설명하지 못해 제안이 약한 프리랜서 |

강한 WHO에는 세 가지가 들어갑니다.

1. 어떤 사람인가
2. 어떤 상황에 있는가
3. 어떤 문제를 겪고 있는가

---

## WHY. 왜 지금 이 강의가 필요한가

WHY는 강의의 필요성입니다.  
사람은 “좋은 내용”이라서 움직이지 않습니다. 지금 자기 문제와 연결될 때 움직입니다.

WHY를 만들 때는 아래 질문을 사용합니다.

| 질문 | 작성 |
|---|---|
| 이 사람은 지금 어떤 문제를 반복하고 있나 |  |
| 이 문제 때문에 어떤 손해를 겪고 있나 |  |
| 이 문제를 방치하면 무엇이 더 어려워지나 |  |
| 이 강의를 들으면 무엇을 시도할 수 있나 |  |
| 이 사람에게 지금 가장 필요한 전환은 무엇인가 |  |

### 예시 1. 커뮤니케이션 강의

약한 표현:

> 커뮤니케이션은 중요하니까 배워야 합니다.

강한 표현:

> 회의에서 생각은 있지만 핵심을 짧게 말하지 못하는 직장인에게, 자기 생각을 1분 안에 정리해 말하는 방법이 필요합니다. 기회는 말을 잘하는 사람에게만 가는 것이 아니라, 자기 생각을 분명히 전달하는 사람에게 먼저 옵니다.

### 예시 2. AI 활용 강의

약한 표현:

> 요즘 AI가 중요하니까 배워야 합니다.

강한 표현:

> 보고서와 기획안을 매번 처음부터 쓰느라 시간이 오래 걸리는 사람에게, AI를 답변 기계가 아니라 질문 파트너로 쓰는 방법이 필요합니다. 중요한 것은 기능을 많이 아는 것이 아니라, 내 문제를 AI가 도울 수 있는 질문으로 바꾸는 능력입니다.

### 예시 3. 예비 강사 강의

약한 표현:

> 강사가 되고 싶은 사람에게 필요한 강의입니다.

강한 표현:

> 자기 경험과 전문성은 있지만 강의 상품으로 정리하지 못한 사람에게, 강의 씨앗을 찾고 대상과 메시지를 정리해 첫 30분 강의안으로 만드는 과정이 필요합니다. 좋은 경험도 구조가 없으면 팔리지 않고, 좋은 지식도 학습자의 변화로 이어지기 어렵습니다.

---

## 사전 질문지가 강의안을 이긴다

기업교육이든 공개과정이든 강의안부터 만들면 놓치는 것이 많습니다.  
먼저 물어야 합니다.

| 물어야 할 것 | 질문 |
|---|---|
| 추진 배경 | 이 강의가 왜 지금 필요한가 |
| 반복 문제 | 학습자는 어떤 장면에서 같은 문제를 겪는가 |
| 기대 변화 | 강의 후 어떤 행동이 달라지길 원하는가 |
| 조심할 맥락 | 피해야 할 표현이나 민감한 상황은 무엇인가 |
| 운영 우선순위 | 분위기, 참여, 시간, 결과물 중 무엇을 특히 중시하는가 |

이 질문이 정리되면 강의안이 단단해집니다.  
왜냐하면 강사는 자기 콘텐츠를 말하는 사람이 아니라, 학습자의 문제를 해결하도록 돕는 사람이기 때문입니다.

# 3단계. WHAT과 강의 정의 문장 만들기

WHAT은 강의의 핵심 내용입니다.  
하지만 WHAT을 많이 넣으면 강의가 좋아지는 것이 아닙니다.

좋은 강의는 설명할 수 있는 내용이 많아도, 학습자가 가져갈 핵심은 짧고 분명합니다.

어린아이도 이해할 수 있을 정도로 짧고 명확해야 합니다.  
누구에게 어떤 이익을 줄 수 있는지, 무엇으로 그것을 가능하게 하는지 담겨야 합니다.

# 4단계. HOW, 오프닝, 질문 설계하기

HOW는 학습자가 강의 안에서 무엇을 하게 만들 것인가입니다.

듣기만 하는 강의는 기억에 오래 가지 않습니다.  
배움은 듣는 시간만으로 완성되지 않습니다.

자기 언어로 한번 말해보고, 적어보고, 정리하는 순간에 이해가 깊어집니다.  
그래서 강의 중간에는 짧게라도 답하게 하고, 공유하게 하고, 적용하게 해야 합니다.

참여 없는 강의는 집중도 낮고, 기억도 빠르게 사라집니다.

---

## 강의 시작은 연결과 공감이다

강의 시작에서 가장 먼저 해야 할 일은 학습자가 강의 주제와 자기 필요를 자연스럽게 잇게 만드는 것입니다.

여기서 환경은 장소나 음향만 뜻하지 않습니다.  
학습자의 뇌와 마음이 배울 준비를 갖춘 상태를 뜻합니다.

학습자는 긴장하거나 어색하면 생각을 짧게 줄입니다.  
처음 만난 사람들 앞에서 지금 힘든 점부터 말하라고 하면 부담을 느낄 수 있습니다.

학습이 잘 되려면 먼저 연결과 공감이 필요합니다.  
편도체가 안정되고 전전두피질이 일할 수 있는 상태가 되어야 합니다.

그래서 아이스브레이킹은 분위기만 푸는 시간이 아닙니다.  
학습자가 서로에 대한 어색함을 줄이고, 오늘 주제가 자기 필요와 닿아 있음을 느끼게 하는 설계입니다.

---

## 좋은 오프닝의 조건

| 약한 오프닝 | 좋은 오프닝 |
|---|---|
| 갑자기 돌아가며 자기소개를 시킨다 | 부담 낮은 질문으로 짧게 반응하게 한다 |
| 강사 이력을 길게 말한다 | 학습자의 필요와 오늘 강의의 연결점을 먼저 만든다 |
| 강의 목표만 읽는다 | 오늘 가져갈 결과물을 분명히 말한다 |
| 분위기만 풀고 주제와 연결하지 않는다 | 가벼운 반응이 주제 이해로 이어지게 한다 |
| 처음부터 어려운 질문을 던진다 | 누구나 답할 수 있는 질문에서 시작한다 |

### 오프닝에서 피해야 할 질문

| 질문 타입 | 설명 | 피해야 할 예시 |
|---|---|---|
| 강제 회고형 | 초반부터 비교 의식과 부담을 키울 수 있다 | 돌아가면서 강의 경험을 말해보세요 |
| 이유 추궁형 | 답은 가능하지만 첫 질문으로는 무겁게 느껴질 수 있다 | 오늘 왜 오셨나요 |
| 문제 고백형 | 관계가 만들어지기 전에는 방어적 반응이 생길 수 있다 | 지금 가장 힘든 점을 말해보세요 |
| 단순 점검형 | 학습자가 자기 생각을 정리하게 만들기 어렵다 | 이해되셨나요 |

### 오프닝에 쓰기 좋은 질문 예시

| 질문 타입 | 설명 | 예시 |
|---|---|---|
| 기대 단어형 | 가볍게 참여 상태를 열고 강의 주제로 들어간다 | 오늘 강의에 오기 전 기대한 것을 한 단어로 적는다면 무엇인가요 |
| 상상 연결형 | 강의가 잘 되었을 때의 변화 장면을 떠올리게 한다 | 내 강의가 잘 만들어진다면 가장 먼저 달라질 장면은 무엇인가요 |
| 상상 대비형 | 정리되지 않았을 때의 손실을 부담 낮게 떠올리게 한다 | 반대로 강의가 계속 정리되지 않으면 가장 아쉬운 점은 무엇인가요 |
| 경험 연결형 | 이미 가진 설명 경험을 강의 주제와 잇는다 | 누군가에게 설명했는데 잘 통했던 순간은 언제였나요 |
| 필요 연결형 | 오늘 얻고 싶은 결과물을 먼저 정리하게 한다 | 오늘 끝날 때 손에 쥐고 싶은 결과물은 무엇인가요 |

가장 좋은 오프닝 질문은 독특한 질문이 아닙니다.  
학습자의 필요와 강의 주제를 정확히 잇는 질문입니다.

## Paired Share. 가장 단순하고 강한 참여 장치

Paired Share는 짝과 짧게 나누는 방식입니다.  
초보 강사에게 특히 좋습니다.

이유는 세 가지입니다.

1. 전체 앞에서 말하는 부담을 줄입니다.
2. 듣기에서 말하기로 상태를 바꿉니다.
3. 학습자가 자기 언어로 내용을 정리하게 만듭니다.

### 운영 방법

| 단계 | 진행 |
|---|---|
| 질문 제시 | 한 번에 하나의 질문만 던진다 |
| 개인 작성 | 30초에서 1분 정도 적게 한다 |
| 짝 나눔 | 1명당 30초에서 1분씩 말하게 한다 |
| 전체 공유 | 2-3명만 짧게 듣는다 |
| 강사 정리 | 공통 포인트를 강의 메시지와 연결한다 |

### 주의할 점

| 상황 | 조정 |
|---|---|
| 질문이 너무 크다 | 한 문장으로 답할 수 있게 줄인다 |
| 시간이 길어진다 | 타이머를 사용한다 |
| 일부만 말한다 | 먼저 개인 작성을 시킨다 |
| 공유가 산만하다 | 강사가 공통 키워드를 정리한다 |

“오늘 배운 내용을 정리해드리겠습니다”도 필요할 수 있습니다.  
하지만 실제 변화는 적용 질문에서 시작됩니다.

# 5단계. IF와 30분 첫 강의안 완성하기

IF는 강의 후 학습자에게 생겨야 할 변화입니다.

좋은 강의는 끝났을 때 이런 문장이 나와야 합니다.

> 그래서 내가 지금 무엇을 해야 하는지 알겠다.

강사가 하고 싶은 말을 많이 했는지가 아니라, 학습자가 다음 행동을 잡았는지가 중요합니다.

---

## IF를 정하는 질문

| 질문 | 작성 |
|---|---|
| 강의 후 학습자가 새롭게 이해해야 할 것은 무엇인가 |  |
| 강의 후 학습자가 바로 작성해야 할 것은 무엇인가 |  |
| 강의 후 학습자가 시도해야 할 행동은 무엇인가 |  |
| 강의 후 학습자가 다른 사람에게 설명할 수 있어야 할 문장은 무엇인가 |  |
| 강의 후 학습자가 더 배우고 싶어 할 다음 주제는 무엇인가 |  |

---

## 30분 첫 강의 구조

처음부터 2시간 강의를 만들려고 하면 복잡해집니다.  
첫 강의는 30분으로 만드세요.

30분 강의는 강의 상품의 최소 단위입니다.  
무료 특강, 커뮤니티 테스트, 내부 공유, 영상 콘텐츠, 세일즈 미팅에 모두 활용할 수 있습니다.

### 기본 구조

| 시간 | 구간 | 목적 |
|---|---|---|
| 0-5분 | 오프닝과 연결 질문 | 학습자가 자기 필요와 연결한다 |
| 5-10분 | 문제 제기 | 왜 이 주제가 지금 필요한지 이해한다 |
| 10-18분 | 핵심 개념 1개 | 변화에 필요한 핵심을 배운다 |
| 18-24분 | 사례와 적용 | 자기 상황에 적용한다 |
| 24-28분 | 작성 또는 나눔 | 자기 언어로 정리한다 |
| 28-30분 | 적용 질문과 다음 안내 | 행동과 후속 학습으로 연결한다 |

# 부록 D. 무료 특강과 본과정의 차이

이 전자책과 무료 라이브 특강만으로도 첫 강의의 방향은 잡을 수 있습니다.  
특히 강의 씨앗, 대상, 한 문장, 30분 구조까지는 혼자 작성할 수 있도록 설계했습니다.

다만 실제 강의는 혼자 만든 초안만으로 완성되기 어렵습니다.

이유는 간단합니다.

1. 내 문장이 다른 사람에게 어떻게 들리는지 혼자 판단하기 어렵습니다.
2. 오프닝 질문이 실제 학습자의 부담을 낮추는지 검토가 필요합니다.
3. 사례가 강의 메시지와 정확히 연결되는지 봐줄 사람이 필요합니다.
4. 질문과 활동의 위치는 실제 운영 흐름 안에서 조정해야 합니다.
5. 강의는 말해보는 순간 약한 구간이 바로 나타납니다.

본과정에서는 아래 작업을 더 깊게 다룹니다.

| 영역 | 본과정에서 하는 일 |
|---|---|
| 강의 정의 문장 | 대상, 메시지, 변화가 더 분명해지도록 피드백 |
| 오프닝 | 학습 환경을 만드는 첫 10분 설계 |
| 질문 설계 | 이해 점검에서 끝나지 않고 정리와 적용을 만드는 질문 구성 |
| 활동 설계 | 짝 나눔, 작성, 공유, 피드백의 위치 조정 |
| 전달력 | 설명, 전환, 강조, 마무리 방식 점검 |
| 미니 시연 | 실제로 말해보고 피드백을 받아 수정 |
| 상품화 | 30분 테스트 강의에서 2시간, 4시간, 과정형 강의로 확장 |

무료 자료는 방향을 잡기 위한 도구입니다.  
본과정은 실제 강의가 현장에서 작동하도록 다듬는 훈련입니다.
