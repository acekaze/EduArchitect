# 03. 팀 탐험 인쇄용 카드 문구 디자인 v1

## 1. 제작 목적

이 문서는 `팀 탐험 보상 카드`를 실제 인쇄물로 만들기 위한 문구와 디자인 규격이다. 카드의 목적은 점수 경쟁을 앞세우는 것이 아니라, 팀 활동을 탐험의 경험으로 바꾸는 데 있다. 참가자는 활동마다 카드를 모으고, 마지막에 탐험 완주 보너스까지 합산해 결과를 만난다.

## 2. 카드 세트 구성

기본 세트는 100장이다.

| 카드 | 점수 | 수량 | 역할 |
| --- | ---: | ---: | --- |
| 깃발 | 6점 | 8장 | 완주와 성취 |
| 나침반 | 5점 | 10장 | 방향과 판단 |
| 지도 | 4점 | 12장 | 구조와 계획 |
| 랜턴 | 3점 | 18장 | 통찰과 관찰 |
| 로프 | 2점 | 24장 | 연결과 협업 |
| 식량 | 1점 | 28장 | 지속과 기본기 |

탐험 완주 조합

- 깃발 1장
- 나침반 1장
- 지도 1장
- 랜턴 1장
- 로프 1장
- 식량 1장

완주 보너스

- 6종을 모두 모으면 9점 추가
- 기본 합산 21점 + 완주 보너스 9점 = 총 30점

## 3. 인쇄 규격

권장 카드 크기

- 포커 카드형: 63mm x 88mm
- 교육용 대형 카드: 70mm x 100mm

1차 제작은 `70mm x 100mm`를 권장한다. 오프라인 강의장에서 팀원이 함께 보기 쉽고, 봉투에 보관하기도 편하다.

인쇄 사양

- 앞면 컬러 인쇄
- 뒷면 단색 또는 2도 인쇄
- 모서리 라운드 3mm
- 무광 코팅
- 종이: 300g 이상
- 재단 여백: 사방 3mm
- 안전 여백: 사방 5mm

## 4. 앞면 공통 구조

앞면 요소

1. 상단 라벨: `TEAM EXPLORATION CARD`
2. 카드명: 깃발, 나침반, 지도, 랜턴, 로프, 식량
3. 점수: `6 POINT`처럼 크게 배치
4. 상징 오브젝트 이미지: 중앙 배치
5. 의미 단어: 완주, 방향, 구조, 통찰, 연결, 지속
6. 짧은 문구: 카드별 메시지

앞면 레이아웃

- 상단 15%: 라벨
- 중앙 45%: 오브젝트 이미지와 카드명
- 하단 25%: 의미 단어와 짧은 문구
- 우측 상단 또는 하단: 점수

## 5. 뒷면 공통 구조

뒷면 문구

```
EXPLORATION CARD
```

뒷면 디자인 방향

- 모든 카드 뒷면은 동일하게 만든다.
- 점수와 카드 종류를 알 수 없게 한다.
- 중앙에는 나침반 아이콘과 `EXPLORATION CARD`만 넣는다.
- 설명 문구는 넣지 않는다.
- 뒷면 색은 차분한 짙은 녹색 또는 먹색을 쓴다.

## 6. 카드별 문구

### 깃발

점수: 6점

역할: 완주와 성취

짧은 문구

```
팀이 끝까지 도착했다.
```

해석 문장

깃발은 활동의 마무리와 결과를 상징한다. 강의에서는 끝까지 해낸 팀의 집중력과 실행을 의미한다.

디자인 방향

- 색상: 딥 레드 또는 선명한 코랄
- 이미지: 천 질감이 있는 탐험 깃발
- 느낌: 마지막 결과, 성취, 환호

### 나침반

점수: 5점

역할: 방향과 판단

짧은 문구

```
팀의 방향이 정해졌다.
```

해석 문장

나침반은 팀이 어디로 가야 하는지 정하는 힘을 상징한다. 강의에서는 좋은 질문과 판단을 의미한다.

디자인 방향

- 색상: 네이비 또는 딥 블루
- 이미지: 금속과 유리 질감이 있는 나침반
- 느낌: 방향, 판단, 리더십

### 지도

점수: 4점

역할: 구조와 계획

짧은 문구

```
길이 한눈에 정리됐다.
```

해석 문장

지도는 복잡한 과제를 구조화하는 힘을 상징한다. 강의에서는 생각을 정리하고 실행 순서를 만드는 역량을 의미한다.

디자인 방향

- 색상: 올리브 또는 차분한 그린
- 이미지: 접힌 종이와 손때가 있는 지도
- 느낌: 구조, 계획, 정리

### 랜턴

점수: 3점

역할: 통찰과 관찰

짧은 문구

```
보이지 않던 길을 비췄다.
```

해석 문장

랜턴은 팀이 놓치던 문제와 가능성을 찾아내는 힘을 상징한다. 강의에서는 관찰, 통찰, 질문을 의미한다.

디자인 방향

- 색상: 앰버 또는 머스터드
- 이미지: 은은한 빛이 있는 손잡이 랜턴
- 느낌: 발견, 관찰, 질문

### 로프

점수: 2점

역할: 연결과 협업

짧은 문구

```
팀이 서로를 연결했다.
```

해석 문장

로프는 혼자 해결하지 않고 함께 움직이는 힘을 상징한다. 강의에서는 협업, 도움, 팀 대화를 의미한다.

디자인 방향

- 색상: 브라운 또는 샌드 베이지
- 이미지: 섬유 결이 살아 있는 로프
- 느낌: 연결, 협업, 신뢰

### 식량

점수: 1점

역할: 지속과 기본기

짧은 문구

```
끝까지 갈 힘을 챙겼다.
```

해석 문장

식량은 탐험을 지속하게 하는 기본 자원을 상징한다. 강의에서는 꾸준한 참여와 작은 실행을 의미한다.

디자인 방향

- 색상: 크림 또는 라이트 카키
- 이미지: 탐험용 식량 주머니
- 느낌: 지속, 기본기, 회복

- 짧은 문구: 10pt
- 뒷면 문구: 11pt

## 9. 이미지 생성 방향

최종 카드는 SVG나 라인 아이콘처럼 보이면 안 된다. HTML 시안은 배치와 문구를 점검하기 위한 구조용이다. 실제 강의용 카드는 AI 이미지 생성 기반의 질감 있는 카드 이미지로 제작한다.

이미지 원칙

- 카드 중앙에는 선 아이콘이 아니라 질감 있는 오브젝트 이미지를 둔다.
- 종이 질감, 잉크 입자, 수채 또는 구아슈 느낌을 살린다.
- 카드명과 점수는 짧고 또렷하게 배치한다.
- 설명 문구는 줄이고 카드 자체의 시각적 매력을 높인다.
- 기업교육 현장에서 유치하게 느껴지지 않도록 색과 장식을 절제한다.

카드별 이미지

- 깃발: 천 질감이 있는 탐험 깃발
- 나침반: 금속과 유리 질감이 있는 나침반
- 지도: 접힌 종이와 손때가 있는 지도
- 랜턴: 은은한 빛이 있는 손잡이 랜턴
- 로프: 섬유 결이 살아 있는 로프
- 식량: 탐험용 식량 주머니

뒷면은 나침반 계열의 상징 이미지와 `EXPLORATION CARD`만 사용한다. 운영 안내나 정산 문구는 넣지 않는다.

## 12. 출력 구성

100장 세트

- 깃발 8장
- 나침반 10장
- 지도 12장
- 랜턴 18장
- 로프 24장
- 식량 28장

테스트 출력 세트

- 깃발 2장
- 나침반 2장
- 지도 3장
- 랜턴 4장
- 로프 5장
- 식량 6장
- 총 22장

테스트 세트는 파일럿 강의에서 사용한다. 실제 강의에서는 100장 세트를 사용한다.

## 13. 제작 체크리스트

- 카드 앞면에 점수가 분명히 보이는가.
- 뒷면에서 카드 종류를 알 수 없게 만들었는가.
- 낮은 점수 카드도 무시되지 않도록 문구가 의미를 갖는가.
- 6종이 함께 모였을 때 탐험 완주 메시지가 자연스러운가.
- 기업교육 현장에서 지나치게 유치하게 느껴지지 않는가.
- 재단 후에도 문구와 점수가 잘리지 않는가.
