# 팀등불 A4 인쇄용 카드 제작 기록 v1

## 제작 범위

`팀 등불` AI 이미지 카드 시안을 A4 출력용으로 배치했다.
등불카드 앞면은 진지한 평가 문장이 아니라 익살과 호들갑이 있는 칭찬 문구로 구성했다.

제작한 인쇄물은 두 묶음이다.

- 등불카드 36장
- 불빛카드 36장

두 묶음 모두 공통 뒷면을 사용한다.

## 인쇄 규격

- 용지: A4 세로
- 해상도: 300dpi
- 카드 크기: 70mm x 100mm
- 배치: A4 한 장당 2열 x 2행, 총 4장
- 재단선: 각 카드 모서리 바깥쪽에 표시

## 불빛 구성

불빛카드는 숫자보다 등불 개수로 보이게 구성한다.

- 작은 불빛: 등불 1개, 18장
- 따뜻한 불빛: 등불 2개, 12장
- 환한 불빛: 등불 3개, 6장

참가자는 진행 중 앞면을 보지 않고 개인이 가지고 있다가 마지막에 동시에 펼친다.

## 출력 안내

- 배율은 `실제 크기` 또는 `100%`로 출력한다.
- 프린터의 `용지에 맞춤` 옵션은 끈다.
- 양면 출력 시 `긴 쪽으로 넘기기`를 사용한다.
- 처음 출력할 때는 1페이지만 테스트한 뒤 앞뒤 위치를 맞춘다.
