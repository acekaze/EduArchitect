# 팀탐험 카드 시각 프레임 통일 작업 기록 v4

## 작업 이유

`v3`는 이미지 캔버스와 흰 외곽 여백을 맞춘 버전이다.  
하지만 카드마다 실제 테두리 선 위치가 달랐다. 특히 로프 카드는 짙은 외곽 프레임이 카드 끝까지 붙어 있고, 식량 카드는 녹색 선이 안쪽으로 들어가 있었다.

인쇄 후 재단하면 카드 크기는 같아도 테두리 위치가 다르게 보일 수 있으므로, 이번에는 공통 프레임을 같은 좌표에 얹는 방식으로 다시 처리했다.

## 처리 방식

- 최종 이미지 크기: `1050 x 1500px`
- 원본 사용: `AI생성_단품카드_프레임외곽맞춤_v3`
- 새 산출물: `AI생성_단품카드_시각프레임통일_v4`
- 공통 바깥 프레임 좌표: `(12, 12, 1038, 1488)`
- 공통 안쪽 선 좌표: `(45, 45, 1005, 1455)`
- 카드별 그림과 텍스트는 유지하고, 바깥 테두리 시각 위치를 통일했다.
