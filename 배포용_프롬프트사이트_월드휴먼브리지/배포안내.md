# 월드휴먼브리지 배포 안내

이 폴더는 월드휴먼브리지용 치트시트 사이트를 수동 업로드할 때 쓰는 최소 배포 폴더입니다.

## 포함된 것

- `index.html`
- `prompts/index.html`
- `prompts/practice-first/index.html`
- `prompts/cheatsheet/index.html`
- `slides/생성형AI_기초활용역량_프롬프트_치트시트_1장.pdf`

## 사용 방법

이 폴더 `배포용_프롬프트사이트_월드휴먼브리지` 자체를 Netlify에 업로드하면 됩니다.

업로드 후 기본 진입점은:

- `/index.html`
- 실제 랜딩은 `/prompts/index.html`

## 권장 동선

1. `practice-first`
2. `cheatsheet`
3. PDF 압축본

## 메모

이 폴더는 웹 배포에 필요한 최소 파일만 담고 있습니다.  
기존 하이닉스 버전과 분리한 월드휴먼브리지 전용 복제본이며, PPT, JS, MD, 작업용 산출물은 포함하지 않았습니다.
