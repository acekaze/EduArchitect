# 홍보 채널 메모 샘플

## 홈페이지 공지

- 목적: 공식 정보 제공
- 필요 내용: 사업명, 일시, 장소, 대상, 신청 방법, 문의처
- 문체: 명확하고 공공기관 문서에 맞게 작성

## 인스타그램

- 목적: 관심 유도와 참여 신청 연결
- 필요 내용: 핵심 이미지 문구, 짧은 소개, 해시태그
- 문체: 가볍지만 과장하지 않게 작성

## 보도자료

- 목적: 사업 취지와 지역 문화도시 방향 설명
- 필요 내용: 사업 배경, 운영 방식, 기대 효과, 담당자 문의처
- 문체: 담백하고 사실 중심으로 작성

## 현장 안내문

- 목적: 참가자 동선과 참여 방법 안내
- 필요 내용: 접수 위치, 운영 시간, 주의사항, 사진 촬영 동의 안내
- 문체: 짧고 바로 이해되게 작성
