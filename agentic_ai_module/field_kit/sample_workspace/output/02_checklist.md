# 운영 체크리스트: AI 교육 현장 점검

교육의 성공은 매끄러운 기술 지원과 안전한 실습 환경에서 시작됩니다. 단계별 항목을 점검하여 참가자가 본질(질문 설계)에 집중할 수 있도록 돕습니다.

## 1. 설치 전 (환경 및 준비물)
- [ ] 강의장 내 모든 좌석의 전원 연결 상태 확인
- [ ] 와이파이(Wi-Fi) 접속 안정성 및 대역폭 점검
- [ ] 참가자 브라우저 최신 버전 업데이트 확인
- [ ] 로그인 가능한 계정(Google/GitHub 등) 사전 준비 안내
- [ ] **샘플 폴더** 다운로드 및 접근 권한 확인

## 2. 설치 및 설정 (현장 실행)
- [ ] 참가자 운영체제(Windows/Mac)에 맞는 설치 파일 안내
- [ ] Antigravity 설치 완료 후 실행 및 첫 로그인 지원
- [ ] 샘플 작업 영역(Workspace) 정상 연동 여부 확인
- [ ] 요청문(Prompt) 입력창 활성화 확인

## 3. 안전 및 보안 세팅 (강조사항)
- [ ] **실제 회사 데이터 제외** 재공지 (육성 및 화면 가이드)
- [ ] 개인정보 및 계정 키 유출 방지 세팅 확인
- [ ] Agentic AI의 '자동 실행' 기능 비활성화 여부 체크 (승인 모드 유지)
- [ ] 모든 결과물이 `output` 폴더에 생성되는지 경로 확인

## 4. 마무리 및 환류
- [ ] 참가자 가이드 배포 및 숙지 여부 확인
- [ ] 리스크 대응표에 기반한 돌발 상황 조치
- [ ] 개별 **'내 업무 적용 문장'** 작성 및 피드백 완료
- [ ] 최종 실습성공 판정 (적용 문장 1개 이상 작성 완료 시)
