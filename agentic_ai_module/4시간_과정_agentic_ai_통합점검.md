# 4시간 과정 Agentic AI 통합 점검

## 과정 성격

- 용도: B2B 직장인 대상 생성형 AI 기본 활용 과정
- 전체 방향: 기능 소개보다 질문, 맥락, 검토, 선택, 위임 설계를 중심에 둔다.
- 추가 방향: 기존 후반부에 있던 Agentic AI 소개를 마지막 50~60분 실습형 모듈로 확장한다.
- 최종 산출물: 각자 자기 업무에 적용할 에이전트 요청문 1개

## 전체 판단

기존 4시간 과정은 Agentic AI를 붙이기에 구조가 좋다.  
이미 앞쪽에서 목적 발견, 인터뷰형 협업, CRAFTO, 10-80-10, 1-3-1, 피드백 루프를 다루기 때문이다.

Agentic AI는 이 흐름의 다음 단계로 배치하면 자연스럽다.

- 앞 3시간: AI에게 좋은 답을 받기 위한 질문과 맥락 설계
- 마지막 1시간: AI에게 일을 맡기기 위한 승인 범위, 완료 조건, 점검 절차 설계

다만 새로 만든 Agentic AI 추가 모듈 51장을 그대로 붙이면 4시간 과정에는 과하다.  
강의용 본편은 12~16장으로 압축하고, 나머지는 보조 자료와 선택 시연용으로 두는 편이 적합하다.

## Agentic AI 구간 구성

### 1. 개념 전환

- 답을 받는 일과 일을 맡기는 일의 차이
- Agent Loop: 계획, 실행, 도구 사용, 결과 점검
- Human Loop: 목적, 승인 범위, 완료 조건, 중단 조건

### 2. 도구 배치

- 공통 실습: Antigravity Fast
- 강사 시연 또는 선택 실습: Codex
- 심화 소개: Hermes
- 비교 소개: OpenClaw, Claude Code
- 다음 과정 연결: MCP, Skill

### 3. 설치와 세팅

- Fast 기반으로 공통 실습을 진행한다.
- 설치 지연자는 페어 실습으로 전환한다.
- 실제 회사 파일, 개인정보, 계정키는 사용하지 않는다.
- 샘플 워크스페이스 안에서만 파일 생성과 수정을 진행한다.

### 4. 첫 요청문 구조

```text
이 폴더 안의 자료만 읽고 교육 운영 준비물을 만들어 주세요.

목적:
참가자 안내문, 운영 체크리스트, 리스크 대응표를 준비하는 것입니다.

자료 범위:
현재 열린 sample_workspace 폴더 안의 input 자료만 사용하세요.

작업 방식:
먼저 작업계획을 제시하고, 제가 승인하면 output 폴더에 파일을 만들어 주세요.

완료 조건:
산출물 3개를 만들고, 각 산출물에 사용한 근거 파일을 함께 적어 주세요.

사람에게 물어볼 조건:
자료가 부족하거나 실제 회사 정보가 필요하면 추정하지 말고 질문하세요.
```

## 슬라이드 반영 방향

- 기존 본편의 마지막 Agentic AI 소개 25분은 50~60분으로 늘린다.
- `충주ai과정_agentic_ai_추가모듈.pptx`는 전체 보관용으로 둔다.
- 4시간 본편에는 아래만 넣는다.
  - 답을 받는 것 vs 일을 맡기는 것
  - Agent Loop / Human Loop
  - 승인 범위와 완료 조건
  - 무료 조건에서의 도구 선택
  - Antigravity Fast 설치 절차
  - 안전한 실습 폴더
  - 첫 요청문
  - Codex 비교 시연
  - Hermes, MCP, Skill 다음 과정 소개
  - 내 업무 적용 문장

## 운영 리스크

- 설치 시간이 15분을 넘으면 페어 실습으로 전환한다.
- 계정 로그인이 안 되는 사람은 강사 화면을 따라 요청문만 작성한다.
- 무료 조건과 모델 연결 방식은 강의 전날 다시 대조한다.
- 설치 성공을 성과로 두지 않는다. 최종 성과는 자기 업무 요청문 1개 작성이다.

## 한 문장 정리

이 4시간 과정은 AI 기능을 더 많이 아는 교육이 아니라, AI에게 더 정확히 묻고, 자료를 더 잘 다루며, 마지막에는 안전하게 일을 맡기는 방법을 익히는 과정이다.
