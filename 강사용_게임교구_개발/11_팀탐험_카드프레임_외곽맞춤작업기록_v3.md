# 팀탐험 카드 프레임 외곽 맞춤 작업 기록 v3

후속 작업: 실제로 보이는 테두리 위치는 `v4`에서 다시 통일했다.  
인쇄와 슬라이드 작업에는 `AI생성_단품카드_시각프레임통일_v4` 폴더를 사용한다.

## 작업 목적

`v2`는 식량 카드의 흰 외곽 여백을 줄였지만, 로프 카드 위아래에 외곽 여백이 있었다. 인쇄 시 카드 프레임이 작게 보일 수 있으므로 실제 외곽 프레임에 맞춰 다시 처리했다.

## 점검 결과

로프 카드 원본에는 좌우 약 16px, 위아래 약 17px 안팎의 외곽 여백이 있었다.

`v3`에서는 카드 외곽을 먼저 자른 뒤 `1050×1500px`로 맞췄다. 로프 카드와 다른 카드 모두 외곽 여백이 없는 상태로 정리했다.
