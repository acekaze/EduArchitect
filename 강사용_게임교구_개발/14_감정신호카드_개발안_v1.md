# 14. 감정신호카드 개발안 v1

## 1. 개발 방향

이미지 카드와 연결하는 방식은 제외한다. 감정 자체를 다루는 카드로 새로 설계한다.

다만 감정카드는 조심해서 만들어야 한다. 감정 이름만 크게 적으면 참여자가 자기 속마음을 공개해야 하는 것처럼 느낄 수 있다. 기업교육 현장에서는 특히 부담이 커질 수 있다.

그래서 이 도구는 감정을 고백하게 만드는 카드가 아니라, 현재 상태를 안전하게 고르고 다음 행동으로 연결하는 `감정 신호 카드`로 만든다.

핵심 문장

감정은 평가가 아니라 신호다. 신호를 알아차리면 다음 행동을 더 잘 고를 수 있다.

## 2. 도구 이름

1차 파일럿 이름: `감정 신호 카드`

이름 후보

- 감정 신호 카드
- 상태 선택 카드
- 감정 온도 카드
- 팀 컨디션 카드
- 마음 상태 카드

추천명은 `감정 신호 카드`다. 감정이라는 단어를 살리되, 상담보다 교육 도구에 가깝게 들린다.

## 3. 사용 목적

- 강의 중 참여자의 현재 상태를 빠르게 파악한다.
- 팀 활동 전에 말하기 부담을 낮춘다.
- 갈등, 피로, 긴장을 평가하지 않고 다룬다.
- 감정을 다음 행동과 연결한다.
- 강사가 참여자의 상태를 강의 주제와 연결해 설명할 수 있게 한다.

## 4. 카드 구성

1차 제작은 36장으로 충분하다.

| 분류 | 역할 | 카드 수 |
| --- | --- | ---: |
| 안정 | 긴장을 낮추고 현재 상태를 정리한다 | 6장 |
| 활력 | 참여 에너지와 기대를 다룬다 | 6장 |
| 긴장 | 압박과 불확실성을 말하게 한다 | 6장 |
| 피로 | 에너지 저하와 거리감을 다룬다 | 6장 |
| 경계 | 불편함과 저항을 안전하게 다룬다 | 6장 |
| 전환 | 배움과 실행으로 이동하게 한다 | 6장 |

확장판은 54장까지 늘릴 수 있다. 하지만 첫 제품은 36장이 좋다. 카드가 너무 많으면 고르는 시간이 길어지고, 강사가 운영하기 어렵다.

## 5. 카드 앞면 구조

각 카드에는 네 가지 요소를 넣는다.

1. 감정 이름
2. 짧은 설명
3. 지금 필요한 것
4. 다음 행동

예시

감정 이름: `부담`

짧은 설명: 해야 할 일이 크거나 많게 느껴지는 상태

지금 필요한 것: 우선순위와 도움 요청

다음 행동: 해야 할 일을 하나로 줄여 말한다

## 6. 카드 뒷면 방향

뒷면은 과한 문구를 넣지 않는다.

추천 문구

- `EMOTION SIGNAL CARD`
- `감정 신호 카드`

디자인 방향

- 앞면은 감정 분류별 색상만 다르게 한다.
- 그림은 넣지 않거나 아주 작은 아이콘만 사용한다.
- 감정 이름은 크게, 설명은 짧게 둔다.
- 참가자가 멀리서도 카드를 쉽게 고를 수 있어야 한다.

## 7. 감정 분류와 색상

| 분류 | 색상 방향 | 사용 이유 |
| --- | --- | --- |
| 안정 | 딥 그린, 세이지 | 차분한 상태 |
| 활력 | 머스터드, 밝은 골드 | 참여 에너지 |
| 긴장 | 오렌지, 코럴 | 압박과 준비 상태 |
| 피로 | 그레이, 블루그레이 | 에너지 저하 |
| 경계 | 버건디, 러스트 | 저항과 불편함 |
| 전환 | 네이비, 틸 | 생각 전환과 실행 |

색상은 감정을 강하게 규정하기보다 구분을 돕는 용도로만 쓴다.

## 8. 운영 방식

### A. 2분 개인 상태 체크

사용 장면

- 강의 시작 직후
- 쉬는 시간 후
- 긴 활동 전

진행

1. 각자 현재 상태와 가까운 감정카드 1장을 고른다.
2. 말하고 싶은 사람만 카드 이름을 말한다.
3. 강사는 전체 분위기를 짧게 읽고 다음 활동으로 넘어간다.

강사 멘트

지금 상태와 가까운 카드를 한 장 골라 주세요. 이유를 꼭 말하지 않아도 됩니다. 오늘 이 상태를 알고 시작하는 것이 목적입니다.

### B. 7분 팀 컨디션 대화

사용 장면

- 팀 활동 전
- 팀 활동 후 회고
- 협업, 리더십, 커뮤니케이션 강의 중간

진행

1. 각자 감정카드 1장을 고른다.
2. 카드 이름만 말한다.
3. 말하고 싶은 사람은 “지금 필요한 것”을 읽는다.
4. 팀은 다음 활동에서 서로 도울 행동 1개를 정한다.

강사 멘트

감정을 설명하라는 뜻이 아닙니다. 지금 팀이 더 잘 활동하기 위해 필요한 신호를 고르는 시간입니다.

### C. 10분 갈등 완화 대화

사용 장면

- 갈등 관리 교육
- 조직문화 교육
- 소통 방식 점검

진행

1. 현재 자주 만나는 감정카드 1장을 고른다.
2. 그 감정이 나쁘다는 평가 없이 “필요한 것”만 읽는다.
3. 팀원은 조언하지 않고 들은 내용을 짧게 반복한다.
4. 각자 다음 행동 1개를 정한다.

강사 멘트

감정을 맞히거나 판단하지 않겠습니다. 오늘은 감정 뒤에 있는 필요와 행동만 다룹니다.

### D. 마무리 실행 연결

사용 장면

- 강의 마지막 10분
- 개인 실행 계획 작성 전

진행

1. 지금 가져가고 싶은 감정카드 1장을 고른다.
2. 카드의 다음 행동을 읽는다.
3. 자기 강의나 업무에 맞게 한 문장으로 바꾼다.
4. 팀원과 30초씩 공유한다.

## 9. 강사용 운영 원칙

### 1. 이유를 강요하지 않는다

참여자는 카드 이름만 말해도 된다. 개인 사정을 자세히 말하게 하지 않는다.

### 2. 감정은 좋고 나쁨으로 나누지 않는다

긴장, 불편함, 서운함도 중요한 정보다. 강사는 특정 감정을 부정적으로 몰아가지 않는다.

### 3. 조언보다 필요한 행동을 다룬다

감정카드 활동은 상담 시간이 아니다. “왜 그런가”보다 “지금 필요한 것은 무엇인가”와 “다음 행동은 무엇인가”로 넘어간다.

### 4. 팀 단위로 회수한다

개인의 감정을 깊게 파고들지 않는다. 팀 활동을 더 잘하기 위해 어떤 지원과 행동이 필요한지 정리한다.

### 5. 강의 주제와 연결한다

강사는 마지막에 한 문장으로 연결한다.

예시

- 감정은 말투와 의사결정에 영향을 줍니다. 그래서 커뮤니케이션에서는 상태 인식이 먼저 필요합니다.
- 팀 활동이 잘 되려면 각자의 에너지와 부담을 함께 다뤄야 합니다.
- AI를 쓰는 과정에서도 불안과 부담이 생깁니다. 그 감정을 알아차리면 질문을 더 구체적으로 설계할 수 있습니다.

## 10. 기존 대안과의 관계

`관점탐색 대화방식카드`는 이미지 카드와 결합할 때 쓸 수 있는 보조 도구로 남긴다.

현재 우선 개발할 도구는 `감정 신호 카드`다. 이미지가 없어도 사용할 수 있고, 강의 오프닝, 팀 활동 전, 갈등 관리, 마무리 성찰에 모두 적용할 수 있다.

## 11. 제작 우선순위

1. 감정카드 36장 문구 확정
2. 카드 앞면 디자인 시안 제작
3. 카드 뒷면 디자인 제작
4. A4 인쇄용 카드 배치 제작
5. 2분, 7분, 10분 운영 슬라이드 제작
6. 매뉴얼북 4장에 반영
