# 리스크 대응표: Agentic AI 실습 돌발 상황 가이드

교육 현장에서 발생할 수 있는 주요 리스크를 사전에 파악하고, 전종목님의 교육 철학에 기반한 대응 메시지를 사전에 준비합니다.

| 상황(Situation) | 대응 전략(Action Strategy) | 참가자 대상 메시지 가이드 (Message) |
| :--- | :--- | :--- |
| **설치 및 실행 불가** | 10분 이상 지연 시 즉시 '페어 실습'으로 전환 | "실행 여부가 여러분의 역량을 증명하지 않습니다. 옆 분과 함께 '설계자'와 '검토자'로 역할을 나누어 업무의 본질적 구조를 설계해 보세요." |
| **인터넷 장애** | 강사 테더링 지원 및 오프라인 이론/시연 중심 진행 | "기술적 환경은 가변적입니다. 지금은 AI에게 일을 시키기 전, 우리가 갖춰야 할 '질문의 구조'를 종이에 먼저 설계해 보겠습니다." |
| **보안 위반 우려** | 즉시 샘플 폴더 외 접근 차단 및 보안 원칙 재강조 | "도구는 도구일 뿐입니다. 우리를 지키는 것은 기술이 아니라 우리의 보안 감각과 승인 절차입니다. 샘플 데이터로 돌아가 안전하게 실험하세요." |
| **Codex/Hermes 복잡도** | 설치를 생략하고 강사 시연(Demo)으로 대체 | "모든 엔진을 소유할 필요는 없습니다. 각 엔진의 특성과 활용 장면을 이해하는 것만으로도 여러분은 충분히 강력한 컨트롤러가 될 수 있습니다." |
| **질문 설계 난항** | 정답을 주는 대신 '메타 인지 질문'으로 유도 | "AI에게 정답을 요구하기보다, 이 업무에서 가장 중요하게 생각하는 판단 조건을 AI에게 알려준다고 생각하고 다시 적어볼까요?" |

## 운영 원칙
1. **기술보다 사람**: 어떤 장애 상황에서도 사람의 질문과 판단이 교육의 주인공임을 잊지 않습니다.
2. **담백한 인정**: 해결 불가능한 기술적 오류는 빠르게 인정하고 우회 경로(시연 등)를 제시하여 교육 흐름을 유지합니다.
3. **존중과 품격**: 질문에 막힌 참가자를 다그치지 않고, 해석의 관점을 열어주는 질문을 던집니다.
