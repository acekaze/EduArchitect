# 04. 팀 탐험 이미지 카드 생성 디자인 브리프 v1

## 1. 정리 목적

이 문서는 `팀 탐험 보상 카드`의 최종 디자인 방향을 정리한 브리프다. 앞서 만든 HTML 카드 시안은 카드 구성, 문구, 점수 배치, 뒷면 문구를 점검하기 위한 구조용 시안이다. 실제 판매용 또는 강의용 카드는 SVG처럼 보이는 라인 아이콘 방식이 아니라, AI 이미지 생성 기반의 질감 있는 카드 이미지로 만든다.

## 2. 핵심 판단

- 최종 카드는 `이미지 카드`로 제작한다.
- 카드의 중심은 선 아이콘이 아니라 질감 있는 오브젝트 이미지다.
- 참가자가 손에 들었을 때 교육용 보드게임 카드처럼 느껴져야 한다.
- 기업교육 현장에서도 유치하지 않도록 색과 타이포를 절제한다.
- 카드 앞면의 문구는 카드명과 점수 중심으로 짧게 둔다.
- 카드 뒷면은 아이콘과 `EXPLORATION CARD`만 사용한다.

## 3. HTML 시안의 역할

HTML 시안은 최종 이미지가 아니다.

사용 목적

- 카드 종류와 점수 체계 정리
- 앞면과 뒷면 문구 점검
- 인쇄물 크기와 여백 감각 점검
- 이후 이미지 생성용 프롬프트를 만들기 위한 기획 보드

사용하지 않을 방식

- SVG 라인 아이콘 그대로 인쇄
- 플랫 벡터 그래픽 중심 디자인
- 단순 도형과 라벨만 있는 카드
- 카드마다 설명 문구가 많은 디자인

## 4. 최종 이미지 방향

전체 무드

- 프리미엄 교육용 카드
- 팀 탐험과 학습 여정의 느낌
- 종이 질감, 잉크 입자, 수채 또는 구아슈 느낌
- 너무 귀엽거나 게임 판타지처럼 과하지 않은 분위기
- 모던한 에디토리얼 카드 디자인

앞면 구성

- 상단: 작은 영문 라벨
- 중앙: 카드별 오브젝트 이미지
- 하단: 카드명과 점수
- 보조 문구는 최소화

뒷면 구성

- 중앙 아이콘
- `EXPLORATION CARD`
- 추가 설명 없음

## 5. 카드별 오브젝트 방향

| 카드 | 점수 | 이미지 방향 | 색감 |
| --- | ---: | --- | --- |
| 깃발 | 6점 | 천 질감이 있는 탐험 깃발 | 딥 레드 |
| 나침반 | 5점 | 금속과 유리 질감의 나침반 | 딥 틸 |
| 지도 | 4점 | 접힌 종이와 손때가 있는 지도 | 올리브 |
| 랜턴 | 3점 | 은은한 빛이 있는 손잡이 랜턴 | 앰버 |
| 로프 | 2점 | 섬유 결이 살아 있는 로프 | 인디고 또는 브라운 |
| 식량 | 1점 | 탐험용 식량 주머니 | 그린 또는 카키 |

## 6. 피해야 할 표현

- SVG처럼 얇은 선만 있는 그래픽
- 무료 아이콘 느낌
- 과한 3D 렌더링
- 네온 컬러
- 만화 캐릭터 느낌
- 판타지 RPG 장비 느낌
- 뒷면에 긴 안내 문구를 넣는 방식
- 점수판처럼 경쟁을 전면에 내세우는 표현

## 7. 생성 프롬프트 원문

아래 프롬프트는 전체 디자인 방향을 잡기 위한 1차 생성용이다. 이후 카드별 단품 이미지를 만들 때는 이 톤을 유지하되 오브젝트별로 나누어 생성한다.

```text
A premium printable card design mockup for a facilitator training game called “EXPLORATION CARD”. Create a single design board showing 7 vertical playing cards: six front cards and one back card. Style: refined tactile raster illustration, not vector, not flat SVG. Paper texture, subtle ink grain, watercolor-gouache mixed with modern editorial design, warm off-white card stock, crisp professional layout. Theme: team expedition and learning journey. Each front card has one large painterly illustrated object centered with rich texture and depth: flag, compass, folded map, lantern, rope, provisions pouch. Use distinct muted colors for each card: deep red flag, teal compass, olive map, amber lantern, indigo rope, green provisions. Keep typography clean and minimal. Korean titles on the fronts: “깃발”, “나침반”, “지도”, “랜턴”, “로프”, “식량”; small point labels: “6점”, “5점”, “4점”, “3점”, “2점”, “1점”. Back card: elegant compass emblem only plus the exact text “EXPLORATION CARD”. No extra slogans. High-end educational workshop card deck, sophisticated, tactile, premium print-ready look. Avoid cartoon style, avoid plastic 3D, avoid neon, avoid flat icon/SVG look. White background behind the card mockup.
```

## 9. 다음 제작 순서

1. 카드별 단품 이미지 6종을 같은 톤으로 생성한다. `완료`
2. 뒷면 이미지를 별도로 생성한다. `완료`
3. 카드명, 점수, 라벨은 인쇄 편집 단계에서 다시 얹는다.
4. 70mm x 100mm 인쇄용으로 재배치한다.
5. 테스트 출력 후 실제 강의장에서 가독성과 손에 쥐는 느낌을 점검한다.
