Antigravity Fast 기반 설치·세팅 가이드

무료 제공 범위에서 먼저 실습하고, 다른 연결은 선택 확장으로 안내한다.

현장 실습용
오늘은 화면에 표시되는 무료 Fast 또는 빠른 기본 모드를 우선 선택한다. 화면 이름이 바뀌면 무료로 제공되는 빠른 모델을 고른다. 고성능 모델, 외부 API, self-hosted 도구는 수업 후 확장 옵션으로 다룬다.

1. 설치 순서

1다운로드 페이지 열기

antigravity.google/download로 이동한다. 브라우저는 Chrome 또는 Edge를 권장한다.

2운영체제 선택

Windows, macOS, Linux 중 본인 노트북에 맞는 설치 파일을 받는다. 설치 권한이 없으면 페어 실습으로 전환한다.

3설치 후 로그인

설치 파일을 실행하고 Google 계정 또는 사용 가능한 계정으로 로그인한다. 로그인 지연 시 강사 화면을 보며 요청문부터 작성한다.

4Fast 기반으로 시작

모델 선택 화면이 나오면 무료 Fast 또는 빠른 기본 모드를 고른다. 오늘은 속도와 안정성을 우선한다.

5샘플 폴더 열기

sample_workspace 폴더를 연다. 실제 회사 자료, 개인정보, 계정키는 넣지 않는다.

6첫 요청문 입력

파일 생성 전 계획과 승인 항목을 먼저 묻게 한다. 결과물은 output 폴더에 만들게 한다.

2. 첫 요청문

이 폴더는 Agentic AI 설치 실습용 샘플 폴더야. 먼저 폴더 안의 자료를 읽고, 1. 네가 이해한 업무 목적 2. 만들 수 있는 산출물 3. 파일을 만들기 전 필요한 질문 4. 승인받아야 할 행동 을 정리해줘. 내가 승인하기 전에는 파일을 만들거나 수정하지 마.

3. Fast 다음에 연결할 것

연결 항목 수업에서 다루는 방식 주의할 점
고성능 모델 Fast로 기본 실습 후, 모델 선택 메뉴에서 고성능 모델을 선택하는 흐름만 보여준다. 요금, 사용량, 계정 상태가 달라질 수 있으므로 전원 실습으로 운영하지 않는다.
Codex 같은 샘플 폴더를 읽고 계획을 제시하는 흐름을 강사 시연으로 비교한다. 무료 계정 사용량과 로그인 상태가 사람마다 다를 수 있다.
Hermes 반복 업무를 기억과 스킬로 축적하는 구조를 심화 시연으로 소개한다. WSL2, 모델/API 설정이 필요해 일반 직장인 현장 설치에는 부담이 크다.
MCP·외부 도구 파일, 브라우저, 일정, 메일 같은 도구 연결의 개념만 다룬다. 외부 발송, 배포, 비용 발생, 개인정보 접근은 반드시 사람 승인 후 진행한다.

4. 운영 문장

오늘의 목표 Antigravity를 설치하고 샘플 폴더에서 첫 에이전트 요청을 실행한다.
오늘의 제한 실제 회사 자료, 개인정보, 계정키, 외부 발송 업무는 쓰지 않는다.
오늘의 결과 내 업무에 적용할 요청문 1개와 승인 범위 1개를 작성한다.
